## Como abrir

Abra index.html no navegador. Não precisa de instalação nem banco de dados.

## Publicar na Vercel

Importe este repositório, escolha o preset Other e use a raiz do repositório. Não é necessário comando de build. O arquivo vercel.json define o diretório de saída.

O botão de WhatsApp abre a conversa com uma mensagem pronta; o visitante decide se quer enviá-la. O site não coleta nem armazena dados de matrícula.
